# ESP32 边缘接收服务启动说明

## 1. 解压并进入目录

在云端笔记本解压本压缩包，然后在 PowerShell 进入解压后的目录：

```powershell
cd <解压目录>
```

## 2. 安装依赖

已有虚拟环境时直接激活；没有时创建一个：

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## 3. 启动服务

推荐先以前台方式启动，便于观察日志：

```powershell
python run_server.py --host 0.0.0.0 --port 8000 --gui
```

如果云端笔记本没有可用的 OpenCV 桌面窗口，去掉 `--gui`：

```powershell
python run_server.py --host 0.0.0.0 --port 8000
```

保持该窗口运行即可。停止服务按 `Ctrl+C`。

## 4. 管理员 PowerShell 放行端口

只需配置一次：

```powershell
Set-NetFirewallRule -DisplayName "Allow camera 8000" -Profile Any
```

如果规则不存在：

```powershell
New-NetFirewallRule -DisplayName "Allow camera 8000" -Direction Inbound -Protocol TCP -LocalPort 8000 -Action Allow -Profile Any
```

## 5. 检查服务

另开一个普通 PowerShell：

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
Invoke-RestMethod http://192.168.1.109:8000/health
```

返回 `status: ok` 即表示服务已启动。

本版本已修复流协议帧头短读问题，并增加了对应测试。替换云端旧目录后必须重启 Python 服务，旧进程不会自动加载新代码。
